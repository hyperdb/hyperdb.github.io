# hyperdb.github.io

このリポジトリは個人サイトとしてGitHub Pagesとして公開するためのソースコードを管理するためのリポジトリです。

## 技術スタック

- vite
- react
- typescript
- eslint 10
- chakra-ui
- wouter
- react-icons
- react-markdown
- remark-gfm
- sqids
- sass-embedded
- mermaid
- highlight.js
- biome

## ページ構成

現状は以下の通りです。少しずつページを追加していく予定です。

- `/`: Home
- `/profile`: プロフィールページ
- `/blog`: ブログ一覧
    - `/posts/:id`: ブログ詳細
